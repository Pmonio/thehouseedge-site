# The House Edge — standalone landing page

A dependency-free, responsive static landing page. No build step is required.

## Preview
Open `index.html` in a browser, or run `python -m http.server 4321` inside this folder and visit http://localhost:4321.

## Deployment
Create a **new** Vercel project (do not reuse the existing House app). Import this folder as a static site with framework preset `Other`, no build command, and output directory `.`. Preview before assigning `thehouseedge.app`. Update Cloudflare DNS only as instructed by Vercel; preserve all email-related DNS records.

## Scope
This site is independent of House 1.0, House 2.0, APIs, databases and Parfait. The interactive probability lab is an illustrative Poisson distribution, not a fixture forecast.
